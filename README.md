# Plataforma PROSPECÇAO AJ

Projeto "Bex Auditoria" - Com base no MD, crie a plataforma "BEX Auditoria" gerando o conceito na estrutura do site "https://www.bdo.com.br/pt-br/bdo-brazil" e no conceito ux do site "https://www.grantthornton.com.br/". Use o documento "SOLUÇÕES ESTRATÉGICAS PARA REESTRUTURAÇÃO FINANCEIRA E GESTÃO DE SOLVÊNCIA (1)" como fonte de informação e complemente. os links da header serão: Insights, Soluções, Sobre nós e Contato.  Gere o conceito de submenus que abrem ao selecionar o link na header.  no link Soluções aplique os sublink menu: Diagnóstico Rápido,  Solvência + Plano de Reestruturação e Consultoria Completa. Crie as páginas seguindo o conceito da página "https://www.grantthornton.com.br/solucoes/"
